# Binbin's Blog

Hexo source for `https://m155-b1nb1n.github.io/binbin-blog/`.

## Local development

```powershell
npm install
npm run server
```

The site is available at `http://localhost:4000/binbin-blog/`.

## Deployment

Push source changes to the `source` branch. GitHub Actions builds the site and publishes the generated files to `main`, which remains the GitHub Pages branch.
